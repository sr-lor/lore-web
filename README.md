# Lore Web Share (منصة مشاركة ومعاينة روابط لور)

مشروع ويب فائق الخفة والسرعة والمصمم بهوية فاخرة (Royal Aesthetic) لمشاركة عناصر منصة لور (روايات، مجتمعات، مقالات، شخصيات).

## المميزات
- **التعرف التلقائي على النطاق (Auto Domain Discovery):** لا يعتمد على أي دومين ثابت، بل يتعرف ديناميكياً على النطاق الذي يعمل عليه.
- **فتح مباشر وفوري للتطبيق (Direct App Launch):** فحص مباشر لمحاولة فتح التطبيق فوراً عند زيارة الرابط من الهاتف إذا كان التطبيق مثبتاً (`lore://`).
- **معاينات وبطاقات اجتماعية (Social Cards & Rich Previews):** مجهزة بالـ Open Graph و Twitter Cards ومحركات البحث.
- **دعم مشاركة المجتمعات:** دعم الرابط المخصص لمجتمعات البرايم (Custom Slugs) والرابط بالمعرف القياسي.
- **استهلاك موارد شبه معدوم:** خفيف جداً، يمكن نشره على AWS S3 + CloudFront أو Vercel أو Cloudflare Pages أو Netlify مجاناً بدون الحاجة لأي خوادم ثقيلة.
- **صفحات المتطلبات النظامية:** سياسة الخصوصية، شروط الاستخدام، وصفحة طلب حذف الحساب.
